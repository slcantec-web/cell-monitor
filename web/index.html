Cell Monitor

Live multi-ISP cell tower scanner for Android. See serving and neighbor cells across dual-SIM networks — bands, PCI, cell ID, signal quality, and quick links to CellMapper.

  • Multi-SIM / multi-ISP — per-cell operator, MCC/MNC, and CID for every tower
  • Serving + neighbors — tech (5G SA/NSA, LTE, 3G, 2G), band, ARFCN, PCI, RSRP/RSRQ/SINR
  • Signal tools — live gauge, quality score, history graph, and band support checks
  • CellMapper — open map links for the towers you see
  • Auto-update — checks this page and prompts when a newer build is available
